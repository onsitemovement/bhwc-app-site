# Becoming Her Women's Collective: web app

This repository is the **built website version** of the members' app, served by GitHub Pages at https://app.becomingherwomenscollective.com.

Don't edit these files by hand. They're generated from the app's source code (a separate, private repository) by `npm run deploy:web`, which rebuilds the app and copies the result here.

Safe to be public: it contains only the app's compiled code and the Supabase project's public key, which is designed to be public and is protected by database rules. Private keys (Square, Supabase service role) are never in here.
